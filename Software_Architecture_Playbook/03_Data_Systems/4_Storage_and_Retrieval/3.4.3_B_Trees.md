## 3.4.3 B-Trees

Book: B-Trees (125–128).

Holds:
- Pages: fixed-size blocks on disk, arranged as a tree. Branching factor = how many child pointers one page holds.
- Lookup: walk from the root page to a leaf page; why 3–4 levels are enough.
- Writes: overwrite the page in place; split the page when it is full.
- Crash safety: what the WAL protects here (a half-done page split).
- Many threads at once: short locks on pages (latches).
- Variants: copy-on-write (write a new page instead of overwriting), shortened keys, pointers to neighbour pages.

Not here: what a WAL is (3.4.2), write amplification (3.4.4).
