## 3.4.5 Index Design

Book: Multicolumn and Secondary Indexes (132), Storing Values Within the Index (133).

Holds two axes:
- What goes into the key:
    - Primary vs secondary index; a secondary index on values that repeat.
    - Composite (multicolumn) index; column order; the leftmost-prefix rule.
- What an index entry holds:
    - A pointer to the row in a heap file (rows stored in no order; the index points into it).
    - The whole row: clustered index.
    - A few extra columns: covering index — the query is answered from the index alone.
- Scenarios: "why is this query slow?"
