### Why care how storage engines work?
<details><summary>Show answer</summary>

You won't write a storage engine (the part of the database that writes data to disk and reads it back), but you will
pick one and configure it. Both need a rough picture of what it does on disk:

- **Pick** — each engine is built for a different kind of load (mostly writes vs mostly reads); you match it to yours.
- **Configure** — a setting only makes sense if you know what it changes inside the engine.

</details>

### Why are database indexes needed?
<details><summary>Show answer</summary>

To efficiently find the value for a particular key. Instead of scanning everything, an index structures the data so you
can locate what you want much faster. Without indexes, searches are slow — and searching the same data in several ways
may need several indexes.

</details>

### What is a database index?
<details><summary>Show answer</summary>

An index is an additional structure that is derived from the primary data. 
Adding or dropping an index doesn't change what the database holds — only how fast queries run.

</details>

### Database indexes — trade-offs?
<details><summary>Show answer</summary>

Faster reads, paid for on writes and disk:

- **Reads** — well-chosen indexes make queries faster.
- **Writes** — slower, sometimes a lot: every write must also update each index.
- **Disk** — each index takes extra space.

</details>

### Which index fits which kind of query?
<details><summary>Show answer</summary>

The kind of query decides how data is stored and indexed:

- **OLTP Systems — find a few rows by key** → a key index, two families:
  - LSM-trees — only append, merge in the background.
  - B-trees — overwrite fixed-size pages in place.
- **OLAP Systems - scan millions of rows, but few columns** (analytics — reports) → not an index: 
  the data is stored by column, so a query reads only the columns it needs.
- **Search by something other than one key** → special indexes:
  - multidimensional — an area on a map;
  - full-text — words in a text;
  - vector — same meaning, different words; "cheap laptop" finds "affordable notebook".

</details>
