## 3.4.6 In-Memory Databases

Book: Keeping Everything in Memory (133–134).

Holds:
- What they are: all data in RAM (Redis; Memcached as a cache).
- Surviving a restart: a log or snapshots on disk, replicas on other machines.
- Why they are fast: they skip turning data into a disk format — not mainly because they skip disk reads.
- Data structures that are hard to keep on disk (e.g. sets and sorted sets in Redis).
- Data bigger than memory: anti-caching — move the least-used data out to disk, load it back when needed.
- Scenarios: "why is Redis fast?", "can Redis lose data?"
