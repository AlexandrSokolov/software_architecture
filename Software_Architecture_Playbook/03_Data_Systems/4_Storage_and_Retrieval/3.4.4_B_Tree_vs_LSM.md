## 3.4.4 B-Tree vs LSM

Book: Comparing B-Trees and LSM-Trees (129–131).

Holds:
- Comparison grid: write cost, read cost, disk space, how steady the response time is.
- Write amplification: one write from the app turns into many writes to disk. The concept card lives here only.
- Sequential vs random writes to disk.
- Background compaction slowing down live requests: spikes in the slowest responses (p99, see Ch. 2).
- Compaction falling behind under heavy writes: files pile up, reads slow down, disk fills up.
- Scenarios: pick an engine for a given workload.
