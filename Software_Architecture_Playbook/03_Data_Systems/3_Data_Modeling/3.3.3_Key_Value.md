Key-value has no section in DDIA Ch. 3, so these come from my own knowledge and Ch. 4/7, not checked against the book:

What it is: key → value, lookup by key only, no query on the value’s content
What it cannot do: joins, lookup by value, and range reads across keys
Redis is more than key → string: hashes, lists, sets, sorted sets (leaderboard)
Typical uses: sessions, rate-limit counters, idempotency keys
Key naming (user:123:session) and expiry (TTL)
