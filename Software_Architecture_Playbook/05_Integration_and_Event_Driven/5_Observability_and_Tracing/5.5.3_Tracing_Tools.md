## Tracing Tools

<details><summary>Show topics</summary>

The products that do tracing in Java and Spring.

- OpenTelemetry: API, SDK, Java agent, Collector, OTLP protocol.
- What the Java agent traces with no code changes: HTTP, Kafka, JMS, RabbitMQ clients.
- Micrometer Tracing: tracing in Spring Boot 3, replaced Spring Cloud Sleuth; runs on OTel or Brave.
- Jaeger and Zipkin: backends that store spans and draw the timeline.
