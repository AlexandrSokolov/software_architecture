## Event Observability

What changes when services talk through a broker instead of direct calls.

- Trace context in message headers; hops that drop headers and break the trace.
- Time in the queue: the gap between the send span and the processing span.
- Batch consumption: one span for many messages from different traces — span links instead of one parent.
- Consumer health: consumer lag, DLQ growth.
