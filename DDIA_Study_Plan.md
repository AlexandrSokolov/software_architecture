## 3. Interview order

Tuned for the senior Java developer role first. Architect notes at the end. This order is the plan and changes with
the role; the folder numbers above are the map and stay fixed.

Each row is one folder: its sections are listed in reading order, and all its cards go into that folder. When a row
builds on sections from another folder, they are listed under **Read first** — read them before the row, and file
their cards in their own folder.

Data moving between systems (`05_`) comes before one database on many machines (`04_`): the first is daily work, the
second has no hands-on practice yet. The exception is `04_Distributed_Data/9_Trouble_with_Distributed_Systems`, pulled
into Milestone 2 because calls between services need it.
